C1 和前后态的衔接

沉浸态不是一个独立页面，是同一个地图实例换皮 + 重新取景： 底图切 amap://styles/blue、只留一台车、画一条发光路线，返回时把这些状态复原。 右上角新增 「⛶ 全屏」：点了就照你那张表格全屏的样式走 —— 左侧菜单、顶栏、页签全部让位， 地图铺满整个窗口，右上角换成红色 「✕ 退出全屏」，其余 HUD 元素位置不变。

进入 / 返回的状态契约

  • 进入前记下：面板宽度、列表滚动位置、底图样式、地图缩放与中心点、当前筛选条件。
  • 退出时还原：只还原这些，不重新拉定位（复用 25s 缓存），列表不闪、不跳。
  • 地图实例复用：不新建 AMap，只 setMapStyle('amap://styles/blue') + 隐藏其他 marker + 画 route 覆盖物；返回时反向执行，避免重建地图导致的闪白。
  • ESC / 返回 / 点空白三种退出方式都走同一个 restore 函数。

沉浸态里为什么没有左侧列表

  • 只有一个任务要看，列表是干扰项 —— 收起后地图可视面积从 732px 变成 992px（+35%）。
  • 切换任务用顶部车牌胶囊（点开是下拉，只有这台车相关的运单：当前 + 还有 N 票）。
  • 想回列表不用退出：左下角留一个 「‹ 列表」 迷你把手，hover 临时浮出。

完整交互闭环

全图监控→ 左侧双行列表（有任务 44px / 空闲 26px）→ 点地图标记 = B1-a 卡片；点列表行 = B3 抽屉→ 「查看物流概览」→ C1 沉浸态（靛青蓝 + 单车主线）→ ← 返回 / ESC
  • 无任务的车：列表里是单行 + 「空闲」徽标；点开卡片/抽屉时按钮变灰，文案「该车暂无进行中运单」。
  • 多票的车：卡片任务块右上角 `还有 2 票 ›`，点开切换，路线重绘但不重建地图。
  • 常驻任务：任务块显示「今日第 2/5 次」，进度按当次趟次；沉浸态节点轴下方同样标注。
  • 定位停更 > 30 分钟：进度条变虚、ETA 位置显示「定位停更」，不给假时间。
还剩两个需要你拍板的：① 沉浸态左下角要不要留「‹ 列表」把手（我倾向于留，成本 0）； ② 点列表行出抽屉、点地图标记出卡片，这个分工你认不认（不认就统一都用卡片）。
