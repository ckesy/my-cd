# 2026-10-22

## 费用明细抽屉（FeeList.vue）修两个问题

用户反馈：① 抽屉里凭证图片全不显示（4 张全是「无图」占位）；② 费用信息和图片分开两段列，
分不清哪张图对应哪笔费用。

**根因**
- `reports.images` 存的是 COS 对象 `{ key, name, size }`，页面却 `map(x => x.fileID || x.url || x)`
  直接丢给 `<el-image :src>` → 每张都走 error 插槽，所以"全部无图"。
- 聚合时把所有费用项的图片 `push` 进同一个 `g.images`，费用列表和凭证区彻底分离。

**改法**
- 新增 `normImgs()` 归一化（兼容 `{key,name}` / 裸 fileID / 裸 http URL），
  `loadImgUrls()` 用 `signGet` 批量换临时链接，带 50 分钟 TTL 缓存（COS 签名 1 小时）。
- 抽屉改为「每笔费用一张卡」：卡上半 = 类型 + 每笔自己的状态圆点 + 描述 + 金额，
  卡下半（虚线分隔、浅灰底）= 这笔自己的凭证缩略图。预览列表只含本笔图片，不串图。
- 非图片凭证（pdf 等）退化成可点的文件块；链接没签下来显示「加载中/未取到」灰块，不让凭证消失。
- `g.images` 汇总字段删掉，不再用页面级 `cur.images`。

**验证**：headless Edge + CDP 打开 /fee/list 点明细，4 张 COS 图正常渲染
（preview 图存 `费用明细-凭证分组-预览.png`），`npm run build` 通过。

## 运单详情「费用情况」tab：默认全展开 + 字号放大

- 展开逻辑由「手风琴（单个 `expandedFee`）」改为「默认全展开」：
  只记 `collapsedFee = ref([])`（被手动收起的 id 数组），`isFeeOpen(r)` 取反；
  刷新数据时清空 → 回到全展开。箭头 up 态表示可收起。
- 字号整体上调一档：费用类型 12.5→14.5、金额 13→15、meta 10.5→12.5、
  明细行 11.5→13、审批链 11.5→13.5/em 10→12、统计数值 16→18、标签 10.5→12，
  缩略图 72×54→88×66，各块 padding 同步加 2px。
- `.fr-items` 加 `max-width: 460px`：宽屏下明细「名称…金额」不再拉成一条长线。
- 验证：CDP 点卡片头，`display` 依次 block→none→block，箭头旋转 180°；build 通过。
  预览图 `运单详情-费用情况-展开预览.png`（1200 视口）。

⚠️ 本机 headless Edge 现在必须加 `--no-sandbox`，否则沙盒初始化失败直接退出；
且必须在同一条 shell 命令里 `&` 启动 + sleep + 跑脚本，跨命令后台进程会被回收。
