## 费用明细抽屉（FeeList.vue）修两个问题

用户反馈：① 抽屉里凭证图片全不显示（4 张全是「无图」占位）；② 费用信息和图片分开两段列，
分不清哪张图对应哪笔费用。

**根因**
- `reports.images` 存的是 COS 对象 `{ key, name, size }`，页面却 `map(x => x.fileID || x.url || x)`
  直接丢给 `<el-image :src>` → 每张都走 error 插槽，所以"全部无图"。
- 聚合时把所有费用项的图片 `push` 进同一个 `g.images`，费用列表和凭证区彻底分离。

**改法**
- 新增 `normImgs()` 归一化（兼容 `{key,name}` / 裸 fileID / 裸 http URL），
  `loadImgUrls()` 用 `signGet` 批量换临时链接，带 50 分钟 TTL 缓存（COS 签名 1 小时）。
- 抽屉改为「每笔费用一张卡」：卡上半 = 类型 + 每笔自己的状态圆点 + 描述 + 金额，
  卡下半（虚线分隔、浅灰底）= 这笔自己的凭证缩略图。预览列表只含本笔图片，不串图。
- 非图片凭证（pdf 等）退化成可点的文件块；链接没签下来显示「加载中/未取到」灰块，不让凭证消失。
- `g.images` 汇总字段删掉，不再用页面级 `cur.images`。

**验证**：headless Edge + CDP 打开 /fee/list 点明细，4 张 COS 图正常渲染
（preview 图存 `费用明细-凭证分组-预览.png`），`npm run build` 通过。

## 组织树：列间虚线对齐条（UserManage.vue，第三轮）

需求：「再加点虚线对齐条」。做了三件事，缺一不可：

1. **虚线用 background 画，不用 `border-left: dashed`**
   border 的虚线节距太碎（约 3px on/off），加上行间有 padding 会断成一截一截。
   改成 `repeating-linear-gradient(to bottom, #C6D3E2 0 5px, transparent 5px 10px)`
   + `background-size: 1px 100%`，并把 `.el-tree-node__content` 的上下 padding 归零，
   行与行首尾相接 → 一条连续的竖虚线。
2. **列容器 `.node-col` 负责画线 + 撑满列宽**，徽章放里面（`justify-self: stretch`
   会把徽章底色拉满整列，所以必须包一层）。
   ⚠️ 每一行都必须渲染 3 个 `.node-col`（内容用 v-if 控制），
   否则机构行 / 车队行缺列 → 竖线断开。
3. **关掉 el-tree 的整行缩进**（`:indent="0"`），层级缩进改成图标列的
   `padding-left: (node.level-1)*16`。这是关键：
   整行缩进会让每层列位置差 18px，虚线呈阶梯状，永远"对不齐"；
   缩进收进图标列后，5 列位置**跨层级完全一致**（实测所有行 node-col 都在 494/590/686）。

列定义：`72px（图标+缩进）| minmax(0,300px) 名称 | 96 车辆 | 96 司机 | 68 状态`，
`gap: 0`（靠列内 padding 拉开距离，虚线才贴得住列边界）。
