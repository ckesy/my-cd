## 读取 workbuddy.cc/p/<code> 分享链接的方法（可复用）

- 分享页是 SPA，`WebFetch` 只能拿到标题。取法：
  1. `POST https://www.workbuddy.cc/space/api/page/share/publish/artifact/list`
     body `{"fileId":"<路径里的 code>"}`（**必须用 www 域名**，裸域会 302 丢 body）
     → 返回 `artifacts[]` + 静态 `url`；
  2. 分享的是「对话」时，静态目录里是 `index.html`（viewer）+ `conversation-data.json`，
     正文全在后者：`messages[].content[]`，元素 `type` 为 `text` / `reasoning` / `tool-call` / `image`。
- 注意：对话分享**只带聊天记录**，当年生成的设计稿 HTML 不在里面。

## headless Edge 截图踩坑（重要）

- ⭐ 本机 Bash 环境带 `HTTP_PROXY/HTTPS_PROXY=http://127.0.0.1:56720`，但 Edge **不读环境变量**，
  走系统代理设置（当前关闭）→ 页面内请求云开发 `FetchError: undefined`，列表 0 条。
  `--proxy-server=...` 也不管用（CORS/直连问题），实际不影响：直连本来通。
- ⭐ 真正原因：**应用首屏的匿名登录没完成就去查库**，导致 `加载数据失败`。
  正确姿势（截图脚本）：先 `Page.navigate` 到 `/`，页面内 `import('/src/utils/supabase.js')`
  并 `await ensureAnonymousLogin()` 预热登录态，**再**导航到目标路由，数据才会出来。
- 脚本模板：`/tmp/shotc.mjs`（注入 `localStorage.currentUser={role:'admin'}` + 预热登录 + 截图）。

### 列表列宽：按实测文本宽度重排（窄屏不再换行/截断）

- 用户反馈「任务类型 / 燃料类型 / 创建账号」太窄：表头换行、单元格变省略号。
  根因不是宽度不够，而是**列宽总和 > 容器宽度**，Element 会把所有列等比压缩
  （表头先换行，正文再截断）。
- 解决步骤：用 canvas `measureText` 量出每列最宽文本的真实宽度，再按
  `列宽 = 文本宽 + 单元格左右内边距(10×2) + 边框` 反推。
  实测（12.5px）：任务编号 19 位 143 / 车队分析报告 75 / 纯电动 38 /
  12345612345 82 / 2026-10-16 70 / 各表头 50。
- 最终列宽：选择 44、编号 180、名称 min120、类型 104、燃料 78、状态 78、
  归属 74、创建账号 110、创建时间 100（合计最小 888），并把 `.cell` 左右 padding
  从 12 收到 10（9 列共省 36px）。
- ⚠️ 两个坑：
  1. **任务编号里的字母宽度不等**（`nwwb` 比 `msjx` 宽 7px），只按一条数据量会漏；
     要扫全表 `scrollWidth > clientWidth` 才算过。
  2. `.text-content` 加 `tabular-nums` 会让数字变宽，反而把「创建账号」挤截断；
     只给日期加（`.date-text`）即可。
- 验证脚本：遍历所有 `td .cell` / `th .cell` 比对 `scrollWidth > clientWidth`，
  在容器 886 / 926 两种宽度下均为 0 溢出。
