## ⭐⭐ 导出 pptx 会丢中英混排文字（重大坑）

- 现象：一个 text 节点里同时含中文和英文/数字时，`export_nodes(format:"pptx")` 只写英文那段 run，
  中文整段消失。例：「3 年车联网行业经验」→ 只剩「3 」；「电动车 4.0（新能源车队开发）」→ 只剩「 4.0」；
  「后市场商品开发部　·　2026.10」→ 只剩「·　2026.10」。纯中文、纯英文（含空格，如「02 / 16」「2024 — 2026」）都正常。
- 判断方法：导出后 `unzip -p xxx.pptx ppt/slides/slide1.xml | grep -o '<a:t>[^<]*</a:t>'`，
  对比设计稿文案，缺行即为中英混排被吃。
- 解决：**一个文本节点只放一种文字体系**。需要「数字 + 中文」并排时，用横向 frame + gap 把
  `["3"]["年车联网行业经验"]`、`["推进落地"]["5+"]["车队适应性改善项目"]` 拆成相邻文本节点，gap 8（28px）/ 8（30px）视觉等于一个空格。
- 导出尺寸：1920×1080 → pptx 18288000×10287000 EMU（20×11.25 英寸），16:9 正确。

## ⭐ pptx 原生动画注入（Ardot 导不出动画）

- Ardot 只能导静态版面，动画要**导出后改 XML**：在 `slide1.xml` 的 `</p:clrMapOvr>` 之后、`</p:sld>` 之前插 `<p:timing>`。
- 可用的最小结构：`p:timing > p:tnLst > p:par > p:cTn(id=1,nodeType=tmRoot) > p:childTnLst > p:seq(concurrent=1,nextAc=seek)`
  → `p:cTn(id=2,nodeType=mainSeq)` 的 childTnLst 里，每个「点击步骤」一个
  `p:par > p:cTn(stCondLst delay="indefinite")`，其中再放每个形状的
  `p:par > p:cTn(presetID=10,presetClass="entr",presetSubtype=0,nodeType=clickEffect|withEffect)`
  → 里面 `p:set`(style.visibility=visible) + `p:animEffect(transition="in" filter="fade")`，stCondLst delay 用来做错峰。
- 坑：每个形状在 `<p:set>` 和 `<p:animEffect>` 各有一个 `p:spTgt`，所以 spTgt 数量 = 形状数 × 2，别当成重复绑定。
- 校验：`p:spTgt` 的 spid 必须都能在 `p:cNvPr@id` 里找到；slide 子元素顺序必须是 `cSld, clrMapOvr, transition?, timing?`。
- 重打包要保留原 zip 内文件顺序（用 zipfile 按 infolist 复制）。
- 交付时同时给一份「_静态备份」，动画结构万一在旧版 PowerPoint 上挑刺可退。

## 工具经验（Ardot slides）

- ⭐ `locate_available_space` 必须传 `pageId`（新文件根页 `0:1`），只传尺寸会报 "Exactly one of nodeId or pageId"。
- ⭐ `capture_layout` 的 `parentId` 必须是容器，**不能传页面 ID**（报 "Root node must be a container"）；逐页传 slide ID。
- ⭐ 用 `fill:"#XXX"` 设底色时，**不要再同时传 `fills:[]`**，会被空数组吃掉 → 元素彻底不可见。
- ⭐⭐ 幻灯片走绝对定位最稳：slide 节点创建时就要 `layout:"none"`。
  新建 frame 的默认布局是 horizontal，**一旦忘了设 none，子元素的 x/y 全部失效**，
  子元素若又误挂到 slide 上，会全部叠在页面左上角（本次 P7 就是这么翻车的）。
- ⭐ 子节点必须在**同一批**里用父节点 binding 作 parent 创建；用别的 ID 建完再 `M()` 移进去虽然可行，
  但坐标语义会跟着换父级，容易错位。
- `export_nodes` 的 `pdf` 只认 frame，不认 slide → 幻灯片合并导出要用 `pptx`；
  `pptx` 按图层顺序合并（本次层序与创建序一致，导出顺序正确，需抽查 slide1/slideN 确认）。
