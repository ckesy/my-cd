二级机构跟一级"平级"排在一起

「晋中分公司」和「山西卡友…」是父子关系，但只靠 14px 缩进区分，视觉上像兄弟。 中间层没车时，这一级甚至直接不出现，树就断了。

2

没有"谁包含谁"的视觉线索

缺引导线、缺层级符号，眼睛只能靠缩进猜。行高一样、字重一样，扫起来没有主次。

3

收起按钮语义不清

顶部这个 ‹ 到底是收整个面板，还是收当前机构？现在点它整块面板消失， 而大多数人以为它只收当前分支。

根因：数据里 organizations 有 id / parent_id / level / is_root 完整父子关系， 我上一版只用了 level 做缩进、按名字分组，没用 parent_id 建树。 所以「先一级、再二级三级」这个顺序天然就不成立。

收起动画

现在生硬是因为：宽度在 400ms 里整体收缩，内容却一直满格显示被硬切，而且用了带 1.56 回弹的贝塞尔，边缘会"弹"一下。 柔和的要点是 分两拍：先让内容淡出，再收宽度；展开反过来，先铺开再淡入。

三套参数的差别

  • 方案 1（推荐）：淡出 120ms → 宽度 260→44 用 300ms cubic-bezier(.4,0,.2,1) → 把手延迟 180ms 淡入。 展开：宽度 320ms cubic-bezier(.22,1,.36,1) → 内容延迟 140ms 淡入 + 8px 右移归位。
  • 方案 2：宽度 + border-radius 12→999px + 阴影收拢，像一条抽屉滑进去；收完变成一个胶囊。 手感俏皮，但和"列表"的语义略偏。
  • 方案 3：整块 translateX(-100%) 滑出（保持 260 宽），右边缘留 12px； 最快最干脆，但会有"整块飞走"的错觉。

别用这些

  • 不要 cubic-bezier(.34,1.56,.64,1)（带回弹）——宽度回弹会让面板边缘"蹦"一下。
  • 不要 用 display:none / visibility 切内容 —— 会闪一下。
  • 不要同时改 width 和 height（现在两个都在动，观感更乱）。
  • 折叠分支（根机构、二级机构）用 max-height + opacity + 每行 14ms 级联延迟，别整块闪现。
5

落地清单

数据结构（这次必须真建树）

  • 用 organizations 的 parent_id 建 childrenMap，is_root/level===1 或 !parent_id 定为根。
  • 根节点永远排第一，子节点按 name 排序；无车的中间层保留（淡显）保证链完整。
  • 车辆按 vehicles.org === 机构名 挂到对应节点；挂不上的进「未分配」。
  • 机构台数 / 任务数递归汇总（和 OrgManage 里 recursiveVehicleMap 一个口径）。

交互细节

  • 默认展开：根 + 二级展开，三级折叠（避免一进来就是瀑布）。
  • 搜索联动：命中车辆时，自动展开它的所有祖先节点；搜索词清空后恢复原展开状态。
  • 记住展开状态：存 sessionStorage，刷新/返回不重置。
  • 根机构折叠：头部 ⌃/⌄ 一键全收/全展（只对分支，不动面板）。
  • 收起面板：右边缘把手，键盘 [ 也能收。
需要你拍板两点： ① 层次用 A（缩进 + 引导线） 还是 B（分块卡片）？我选 A，260px 下更耐看。 ② 收起把手放右边缘（①）还是底部圆钮（③）？我选 ①。 另外确认一下：空机构（0 台车）要不要显示？我建议显示但淡显，否则层级会断。
