全图监控 · 车辆浮标「剩余里程 / 预计送达」方案

目标：在车辆标记旁边就地读出 还剩多少公里、几点到，不用点开气泡。 数据来自 waybillProgress：剩余里程 = plan_distance − 已行驶（已行驶自 depart_time 起算）， 剩余时间 = plan_duration × 剩余比例，ETA = 现在 + 剩余时间。只有带在途任务的车才有这组数。

我建议的落地方式：A/D 常显 + C 升级

不新增交互，全部复用现有 hover / 点击

全图监控的价值是「一眼看全局」，而 C 这种大卡片一旦常显，两台车靠近就互相咬住，还会盖住你的紫色轨迹线——那是这个页面最重要的东西。 所以：常态只用 A 或 D 的紧凑形态（垂直多占 16px、水平几乎不增），鼠标移到车上才升级成 C； 点击仍然是现在那个完整气泡（速度 / 海拔 / 机构 / 查看物流概览），三层信息由浅到深，互不抢位。
