换肤配色 · 四个方案

只换主色系，布局和字号不动。
选色的前提是避开已有状态色：橙=待审核、蓝=待打款/在途、青=已通过、绿=已完成、红=异常/驳回。

我的建议：A 石墨做默认，B 藏青做备选。

你现在的痛点是「红色看久了累」。红色的刺激来自**高饱和 + 大量面积**（KPI 主卡、按钮、选中态全是红）。 换成石墨后，界面几乎只有黑白灰 + 状态色，状态色反而更跳 —— 待审核的橙、已完成的绿会因为背景变素而更容易被注意到，这其实是加分。

如果觉得纯灰太素，选 B 藏青：有颜色但饱和度低，深蓝在屏幕上比红色柔和得多。

实现方式（只改配色，不动布局）

第一步把散落的 86 处硬编码收成变量：#C8102E 36 处、#D32F2F 49 处、#8E0A20 1 处，分布在 7 个文件。

第二步在根节点挂 data-theme，用 CSS 变量切换： 

:root[data-theme="graphite"] {
  --brand:       #1F2937;   /* 主色：按钮、选中态、强调数字 */
  --brand-hover: #374151;
  --brand-light: #F1F5F9;   /* 浅底：选中行、标签背景 */
  --brand-dark:  #0F172A;   /* 深色：主卡渐变终点 */
}

主题存 localStorage.theme，刷新不丢。想更省事也可以只做石墨一个主题 + 一个「恢复默认红」的开关，不搞多套。
