## 画布与母版（1280 × 720）
| 区 | 位置 | 说明 |
|---|---|---|
| 安全区 | padding 40px 64px 24px 64px | 内容不得越界 |
| A 标题块 | y 40–118（高 78） | 眉标 12px + 主标题 34px Bold，右下可放一句副标 |
| B 内容区 | y 118–656（高 538） | 截图 / 卡片 / 图表 |
| C 页脚条 | y 664–696 | 左：车队一体化运营平台　右：NN / 14（12px #9AA3AF） |
| 封面 / 收束页 | 自定义 | 深色底 #111827 |

## 颜色（4 色 + 白）
| 角色 | hex | 用法 |
|---|---|---|
| 主色 品牌红 | `#C8102E` | 强调线、关键词、主按钮、页码竖条 |
| 墨黑 | `#111827` | 标题、深色页底、巨型数字 |
| 冷灰 | `#F4F5F7` | 浅底面板、卡片底、表格斑马 |
| 中灰 | `#6B7280` | 正文次要信息、注释 |
| 白 | `#FFFFFF` | 页面底、卡片 |

面积分配：常规页 白/冷灰 ≥ 75%，墨黑 15%，品牌红 ≤ 8%；hero 页（02/04/09/13）品牌红可到 15%。
渐变：仅封面与收束页使用 `linear-gradient(135deg,#111827 0%,#1E2635 100%)`，其余不用渐变。

## 字体
| 层级 | 字号 / 字重 / 行高 |
|---|---|
| 封面主标题 | 60 / 800 / 1.16 |
| 章节大字（收束） | 56 / 800 / 1.2 |
| 页面主标题 | 34 / 700 / 1.25 |
| 眉标（小标签） | 12 / 700 / 1.0，letterSpacing 2，红 |
| 卡片标题 | 20 / 700 / 1.4 |
| 正文 | 15 / 400 / 1.75 |
| 注释 | 12.5 / 400 / 1.6 |
| 巨型数字 | 64–76 / 800 / 1.0 |
| 页码 | 12 / 400 |

字体家族：`PingFang SC`（标题与正文同一家族，靠字重/字号区分）。
数字统一 `fontVariantNumeric` 不生效，改用 letterSpacing 收紧 + 800 字重。

## 母版元素
- 标题块左侧 4px × 28px 品牌红竖条；眉标在竖条右侧，主标题在下方。
- 页脚左下角 10px 小字项目名，右下角 `NN / 14`。
- 截图统一走「浏览器窗口卡」（已含顶部圆点条）+ 12 圆角 + 柔和投影；手机截图走「圆角 20 + 细边框 + 投影」。

## 硬约束
- 相邻页不得使用相同版式（左文右图 / 右文左图交替）
- 每页至少 1 个视觉锚点：≥ 48px 数字、或占 B 区 ≥ 40% 的截图
- 正文字号 ≥ 15px（注释 ≥ 12.5px）
- 品牌红只出现在：竖条、关键词、数字单位、按钮、结论条
