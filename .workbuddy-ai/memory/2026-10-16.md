## 路线弹窗「放不下」根治（结构方案，弃用 vh 硬算）
- 用户反馈：弹窗仍然太大、底部按钮看不全。
- 关键证据：用户说「还是太大」→ 说明弹窗确实变成 `min(1440px,96vw)≈96vw` 满宽 → **证明 `.route-form-dialog.el-dialog` 同元素选择器已生效**（即上一轮的选择器修正是对的）。
- 根治思路：不再用 `height: calc(96vh - 220px)` 这种「猜 chrome 高度」的写法，改成结构性约束：
  - `.route-form-dialog.el-dialog { display:flex; flex-direction:column; height: min(820px, calc(96vh - 90px)); width: min(1360px,92vw) }`
    （可用高度 = 100vh − margin-top 4vh − margin-bottom 50px，留 40px 余量；`el-dialog` 默认 `margin: 4vh auto 50px`）
  - `.el-dialog__header / __footer { flex-shrink: 0 }`（头尾不被压缩）
  - `.el-dialog__body { flex:1; min-height:0; overflow:hidden; display:flex; flex-direction:column }`
  - `.rf-stage { flex:1; min-height:0; height: calc(96vh - 220px) /*兜底：父级非 flex 时*/ }`
- 结论：弹窗高度 = min(820px, 96vh−90px)，总占用 ≤ 100vh−40px，**数学上保证放得下**；地图区自动吃剩余空间。

## ⭐⭐ 路线弹窗「只能拖动才看全」的真正根因（重大）
- 症状：弹窗左边缘贴着**内容区**左边（不是视口居中），右侧溢出屏幕，底部也被裁 → 只能左右上下拖。
- 根因：**`<el-dialog>` 的 `append-to-body` 默认 false**（EP 2.14 源码确认 `appendToBody: Boolean`，默认 false），弹窗渲染在页面内；而 Dashboard 的 `.content-wrapper` 带 `animate-fade-up` 动画（`transform: translateY(0)` 被 `forwards` 保留）→ **带 transform 的祖先成为 `position: fixed` 的包含块** → `.el-overlay{position:fixed;inset:0}` 被限制在内容区内，而不是整个视口。
  - 这也解释了为什么 `88vw` 会溢出：vw 是视口单位，但容器只有「视口 − 侧边栏 220px」宽。
- 修法：给 `<el-dialog>` 加 **`append-to-body`**（teleport 到 body），遮罩恢复全视口。
- ⚠️ 全项目所有 el-dialog 都没写 `append-to-body`，同样受影响（小弹窗因尺寸小没暴露）。**后续做大弹窗/需要全屏居中的弹窗时必须加 `append-to-body`。**
- 本次同时做了紧凑化：弹窗 `width: min(1280px,88vw)`、`height: min(760px, calc(96vh - 80px))`；卡片 `clamp(280px,28vw,400px)` / `clamp(320px,34vw,470px)`；`.card-body` padding 18/22→14/16；`.info-form .el-form-item` margin-bottom 18→12。
- `npm run build` 通过。

## 修复：编辑圆形围栏时地图不跳到围栏
- 文件：`src/components/AddEleFenceDialog.vue` → `loadEditData()`
- 根因：⭐ 圆形分支只调了 `drawCircle(lng, lat)`（内部只执行 `circle.setCenter(...)`，改的是 **Circle 对象**的中心）**并 `map.setZoom(14)`，但从未调用 `map.setCenter()`**；而 polygon/polyline/district 分支都调了 `map.setFitView(...)`，所以能自动跳过去。→ 表现为「只有圆形的不会跳」。
- 修法：圆形分支补上 `map.setCenter([lng, lat])`，并加 `isNaN` 守卫避免脏数据把地图飞走。
- 地图实例用 `new AMapInstance.Map('fence-map-container', ...)` 按 id 创建，与 `append-to-body` 无关，不受上一条改动影响。
- `npm run build` 通过。
